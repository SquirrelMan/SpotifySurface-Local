# SpotifySurface Local v1.1.0

- Transparent, borderless lyrics overlay: only the current lyric and a small upper-right settings button remain visible.
- Track information, connection status, timing offset, window dimensions, and Quit are available through the **⋯** button.
- Drag the lyric text to move the overlay. Font size continues to adapt to the available space.
- Existing token-free Spotify synchronization and playback-clock fixes are retained.

Download **SpotifySurface.exe**, open Spotify desktop on Windows, and play a song. No Python, conda, or API token is required. Synced lyrics depend on LRCLIB coverage. The EXE is unsigned.

Based on [PureAspiration/SpotifySurface](https://github.com/PureAspiration/SpotifySurface), retaining original author credit and the MIT license.
