# SpotifySurface Local v1.1.1

- Fixes overlay dragging by making the upper-right **⋯** button a reliable drag handle.
- Click the button to open settings; hold and drag it to move the lyrics overlay.
- Mouse capture keeps dragging active after the pointer leaves the button or visible lyric strokes.
- Transparent spaces continue to pass mouse input through to underlying windows.
- Adds a settings checkbox to switch between transparent and solid dark backgrounds. The solid lyric area is fully draggable.

Download **SpotifySurface.exe** and run it while Spotify desktop is playing on Windows. No API token, Python, or conda is required.

Based on [PureAspiration/SpotifySurface](https://github.com/PureAspiration/SpotifySurface), with original attribution and MIT license retained.
