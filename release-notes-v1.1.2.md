# SpotifySurface Local v1.1.2

- Changes the settings window title, background toggle, timing offset, size controls, and Quit button to English.
- Changes connection, loading, and missing-lyrics messages to English.
- Preserves lyrics in their original language.
- Retains transparent/dark background switching and dragging through the upper-right **⋯** button.

Download **SpotifySurface.exe** and run it while Spotify desktop is playing on Windows. No API token, Python, or conda is required.

Based on [PureAspiration/SpotifySurface](https://github.com/PureAspiration/SpotifySurface), retaining original attribution and the MIT license.
