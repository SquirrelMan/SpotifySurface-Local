# SpotifySurface Local v1.1.3

- Uses a neutral music-note icon for the EXE and application windows, replacing inherited default icons.
- Keeps the English interface, optional transparent background, and draggable lyrics overlay.

Download **SpotifySurface.exe** and run it while Spotify desktop is playing on Windows.

Based on [PureAspiration/SpotifySurface](https://github.com/PureAspiration/SpotifySurface), retaining original attribution and the MIT license.
